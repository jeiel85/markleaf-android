Markleaf is a lightweight, local-first Markdown note app for Android.

Write plain Markdown, organize with inline tags, search instantly, and keep your notes under your control. Markleaf stores notes in a local Room database and does not declare the INTERNET permission.

Key features:

* Markdown editor with preview
* Tags written directly in note bodies
* Fast local full-text search
* Pin, archive, trash, and restore flows
* Wikilinks and backlinks
* Image attachments stored in app-private storage
* Single-note and all-notes Markdown export
* SAF folder mirror for user-controlled external sync folders
* Light, dark, and Material You color options
* Tablet two-pane layout

Privacy and distribution:

* No account
* No Markleaf server
* No analytics, ads, tracking, Firebase, or proprietary crash reporting SDK
* No INTERNET permission
* Android Auto Backup disabled
* User data leaves the device only through explicit OS-mediated actions such as export, share, external link opening, or a user-selected SAF folder
