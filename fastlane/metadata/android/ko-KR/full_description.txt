Markleaf는 Android용 가벼운 로컬 우선 Markdown 메모 앱입니다.

표준 Markdown으로 빠르게 쓰고, 본문 안의 태그로 정리하며, 로컬에서 즉시 검색할 수 있습니다. Markleaf는 노트를 기기 내부 Room 데이터베이스에 저장하고 INTERNET 권한을 선언하지 않습니다.

주요 기능:

* Markdown 편집기와 미리보기
* 노트 본문에 직접 쓰는 태그
* 빠른 로컬 전문 검색
* 고정, 보관, 휴지통, 복원 흐름
* 위키링크와 백링크
* 앱 내부 저장소에 보관되는 이미지 첨부
* 단일 노트 및 전체 노트 Markdown 내보내기
* 사용자가 선택한 SAF 폴더로 미러링하는 외부 동기화 보조 기능
* 라이트/다크 모드와 Material You 색상 옵션
* 태블릿 2-pane 레이아웃

개인정보와 배포 원칙:

* 계정 없음
* Markleaf 서버 없음
* 분석, 광고, 추적, Firebase, 폐쇄형 크래시 리포팅 SDK 없음
* INTERNET 권한 없음
* Android 자동 백업 제외
* 데이터는 내보내기, 공유, 외부 링크 열기, 사용자가 선택한 SAF 폴더 같은 명시적인 OS 경로를 통해서만 기기 밖으로 이동할 수 있습니다
