Markleaf は Android 向けのローカルファースト Markdown ノートアプリです。

シンプルな Markdown で書き、本文内のタグで整理し、ローカルで即座に検索でき、ノートはあなたの手元に残ります。Markleaf はノートをローカルの Room データベースに保存し、INTERNET 権限を宣言しません。

作成とプレビュー:

* リアルタイム Markdown プレビューとライブのシンタックスカラーリング
* GFM テーブル、チェックボックス、引用、コールアウト(> [!NOTE] …)
* 10 言語に対応したコードブロックのシンタックスハイライト
* 脚注の参照 ↔ 定義ジャンプ、Wikilink とバックリンク
* 選択範囲や単語を太字/斜体/取り消し線/コードで囲むスマートフォーマット
* フォーカスモード、単語数・読了時間の統計、ノート内の検索・置換

整理と探索:

* 本文に #タグ を書くだけで自動インデックス(フォルダ不要)
* クイックスイッチャーと SQLite FTS の全文検索
* ピン留め、アーカイブ、ゴミ箱、復元のフロー

同期と取り込み(No-Cloud):

* SAF で選んだフォルダに各ノートを .md ファイルとしてミラーリング
* 外部の .md / .txt ファイルを開く・共有で取り込み
* 単一ノートおよび全ノートの Markdown エクスポート、システム共有

デザインとアクセシビリティ:

* ホーム画面ウィジェット、生体認証ロック、スクリーンショット遮断オプション
* ライト / ダーク / Material You、タブレット向け 2ペインレイアウト
* 7 言語の UI(韓国語、英語、スペイン語、日本語、フランス語、ドイツ語、簡体字中国語)

プライバシーと配布:

* アカウントなし、Markleaf サーバーなし
* アナリティクス、広告、トラッキング、Firebase、独自クラッシュレポート SDK なし
* INTERNET 権限なし、Android 自動バックアップ無効
* ユーザーデータはエクスポート、共有、外部リンクの起動、ユーザー指定の SAF フォルダといった明示的な OS 経由の操作でのみ端末外へ出ます
