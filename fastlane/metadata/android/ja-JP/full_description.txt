Markleaf は Android 向けの軽量なローカルファースト Markdown ノートアプリです。

シンプルな Markdown で書き、本文内のタグで整理し、ローカルで即座に検索でき、ノートはあなたの手元に残ります。Markleaf はノートをローカルの Room データベースに保存し、INTERNET 権限を宣言しません。

主な機能:

* プレビュー付き Markdown エディタ
* ノート本文に直接書けるタグ
* 高速なローカル全文検索
* ピン留め、アーカイブ、ゴミ箱、復元のフロー
* Wikilink とバックリンク
* アプリ専用ストレージに保存される画像添付
* 単一ノートおよび全ノートの Markdown エクスポート
* ユーザー指定の SAF フォルダにミラーする外部同期補助
* ライト / ダーク / Material You カラー
* タブレット向け 2ペインレイアウト

プライバシーと配布:

* アカウントなし
* Markleaf サーバーなし
* アナリティクス、広告、トラッキング、Firebase、独自クラッシュレポート SDK なし
* INTERNET 権限なし
* Android 自動バックアップ無効
* ユーザーデータはエクスポート、共有、外部リンクの起動、ユーザー指定の SAF フォルダといった明示的な OS 経由の操作でのみ端末外へ出ます
