本物の書き心地

ツールは一歩引いて、
言葉が流れ続ける。

開く、書く、整理する、見つける、書き出す — そのすべてが一台の端末の中で自然につながります。

01 · 書く

構文は生きたまま、ツールは必要なときだけ現れる。

Markdown の原文はそのままに、見出しや強調は編集中も読みやすく表示されます。小さな Aa ボタン、選択範囲に応じたアクション、行頭の / コマンドで、画面を散らかすことなく書式を追加できます。

  • Live Markdown と CommonMark/GFM プレビュー
  • 書式ツールバー、自分で作るスニペットボタン、キーボードショートカット
  • 表・コールアウト・Wikiリンクのクイック挿入

02 · 整理して見つける

フォルダに悩む前に、タグを付け、リンクし、検索する。

本文の #タグ がそのまま分類になり、SQLite FTS 検索とクイックスイッチャーが、多くのノートの中でも次の思考へすばやく導きます。

  • ネストしたタグとタグごとのノート閲覧
  • Wikiリンクとバックリンク
  • 複数のノートをまとめて選び、ピン留め・アーカイブ・ゴミ箱へ

03 · 所有して持ち出す

アプリの外でも読めるファイルとして残す。

すべてのノートを標準の Markdown として書き出したり、自分で選んだ SAF フォルダにミラーリングしたりできます。PDF を共有したいときも、元の .md はそのまま残ります。

  • 個別・全ノートの Markdown エクスポート
  • 自分で選んだフォルダにミラー
  • 画像も入る PDF 書き出しと Android の共有シート

04 · 使っているフォルダのまま

すでに使っている Markdown フォルダをそのまま指定。

Markleaf に独自のボルト形式はありません。Obsidian や Logseq、テキストエディタが作ったファイルをそのままノートとして受け入れ、そのファイルが持っていたフロントマターは手を付けずに返します。

  • 既存の .md を複製せずそのまま引き継ぎ
  • 他のツールが書いたフロントマターキーも往復で保持
  • フォルダ 1 階層のみ — Markleaf はタグで整理
実際のボルトにつなぐ前に知っておくこと

ほかにも

小さな機能を、
毎週ひとつずつ。

その多くは Issues や Discussions に寄せられた要望から始まりました。新しいバージョンはほぼ毎週リリースされます。

  • ホーム画面ウィジェット

    最近のノート一覧か 1 つのノートを、好きな色で、壁紙を好きなだけ透かして置けます。

  • 今日のノート

    新規ノートのショートカットで、日付をタイトルにしたその日のノートを開き、すぐに一行書き足せます。

  • ロックしたノート

    一部のノートをパスコードで守り、アプリ全体をロックし、スクリーンショットや最近使ったアプリの画面からノートを隠せます。

  • タブレットと折りたたみ端末

    タグレール・ノート一覧・エディタを並べて表示し、画面を回転しても開いたノートはそのままです。

  • 自分好みの見た目

    Markleaf グリーンまたは Material You、ダークモード、行間、手持ちの .ttf・.otf フォント。

  • 画像

    代替テキスト付きで画像を添付できます。画像はアプリ内に保存され、PDF にも入ります。

  • どんな Markdown ファイルも読める

    .md や .txt ファイルを開くとレンダリングして表示します。保存したときだけノートに加わります。

  • やさしいゴミ箱

    ゴミ箱に移した直後に元に戻したり、あとで復元したり、決めた期間が過ぎたら自動で空にしたりできます。

Privacy by architecture

何も送らないことが、
いちばん確かな保護。

F-Droid・Google Play 版はインターネット権限をまったく宣言しません。ノート・タグ・添付ファイル・設定は、あなたが自分で移すと決めるまでアプリ専用ストレージにとどまり、どのビルドでも送信されることはありません。

F-Droid / Google Play: android.permission.INTERNET = false

例外はひとつだけです。GitHub Releases の -sideload APK はアップデートを確認できますが、オンにしたときだけ動作し、そのときもノートのデータは送信しません。

プライバシーポリシーの全文を読む
