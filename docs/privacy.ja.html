Markleaf プライバシーポリシー

最終更新: 2026年5月26日 · 対象: Markleaf Android v2.x

基本原則

Markleaf はローカルファーストの Markdown メモアプリです。独自のサーバーを運用せず、ノート、タグ、添付ファイル、メタデータを外部サーバーへアップロードすることは一切ありません。F-Droid と Google Play で配布されるビルドには android.permission.INTERNET 権限がまったくなく、GitHub Releases のサイドロード版は下記 ネットワーク の用途ひとつのためだけにこの権限を宣言します。

Markleaf が収集しない情報

  • 氏名、メールアドレス、連絡先、位置情報
  • アカウントまたはログイン情報
  • ノート本文、タイトル、タグ、添付画像、ファイル名、メタデータ
  • 使用統計、テレメトリ、分析イベント、広告識別子
  • クラッシュレポートや端末識別子

また、分析、広告、トラッキング、リモート設定、Firebase、クローズドソースのクラッシュレポート SDK も含まれていません。

ネットワーク

アプリをどこから入手したかによって異なります。いずれの場合も、ノートのデータが送信されることはありません。

  • F-Droid・Google Play — android.permission.INTERNET 権限がなく、ネットワーク動作も一切ありません。
  • GitHub Releases（サイドロード） — 用途はただひとつ、自分でオンにしない限り動かないアップデート確認のためにこの権限を宣言します。
F-Droid / Google Play   android.permission.INTERNET   なし
GitHub Releases         android.permission.INTERNET   アップデート確認のみ

サイドロード版のアップデート確認

  • 既定はオフです。 設定で自分でオンにするまで何も起こりません。
  • オンにすると 1 日 1 回、最新リリース情報が入った静的な JSON ファイルを 1 つ GET します。確認に失敗した場合は黙って見送ります。
  • リクエストに乗るのはその URL と標準的な HTTP ヘッダーだけです。クエリ文字列もクッキーもアカウントもありません。
  • ノート本文・タイトル・タグ・添付・ファイル名・メタデータ・端末識別子・利用履歴が送信されることはありません。 これはどのビルドでも例外がありません。
  • 新しいバージョンがある場合、ダウンロードは端末のブラウザに引き渡します。アプリ自身がダウンロードやインストールを行うことはありません。
  • ストア版にはこの機能の権限もコードも含まれていません。無効化されているのではなく、ビルドに入っていません。

データの保存場所

  • ノート本文、タイトル、タグインデックスは、アプリ内部の Room データベースに保存されます。
  • ユーザー設定は DataStore に保存されます。
  • 添付画像はアプリ内部ストレージにコピーされ、保存時に機微な EXIF メタデータを除去します。

Android システムバックアップポリシー

Markleaf は android:allowBackup="false" を設定し、Android 自動バックアップおよび端末間転送からアプリのデータを除外します。新しい端末への移行や複数端末での利用が必要な場合は、Markdown エクスポート、共有、または SAF フォルダミラーをご自身で選択します。

ユーザー主導のデータ移動

以下の操作は、ご自身が実行した場合にのみ発生し、Android の明示的な権限ダイアログ、またはご自身が行う UI 上の選択を経由します。

  • 個別のノートまたは全ノートを Markdown（.md）としてエクスポート
  • Android システムの共有シートでノートのテキストまたはファイルを共有
  • 本文内の外部リンクをタップして OS / 既定のブラウザに委譲
  • クリップボードへコピー
  • ご自身が選択した SAF フォルダへ Markdown ファイルをミラーリング

SAF フォルダが Drive、Dropbox、OneDrive、Syncthing、NAS マウントといった外部同期クライアントによって同期されるかどうかは、その外部アプリの責任です。Markleaf 自体がその同期を行うことはありません。

権限

Markleaf が宣言するランタイム的な権限は、触覚フィードバックのための android.permission.VIBRATE のみです。位置情報、マイク、カメラ、連絡先、通知、外部ストレージの読み取り、メディアの読み取りに関する権限は、どのビルドにもありません。android.permission.INTERNET は F-Droid・Google Play 版には存在せず、サイドロード版にのみあり、用途は上記 ネットワーク のアップデート確認だけです。
