# Markleaf へようこそ

Markleaf は Android 向けのローカルファースト Markdown ノートアプリです。すぐに開けて、書くときは静かで、テキストはそのままの Markdown として残ります。

## まず試してみる

- **+** をタップして新しいノートを始める
- ツールバーで見出し・リスト・太字・コード・引用などを適用
- 上部の **プレビュー** をタップしてレンダリング結果を確認
- 一覧でノートを長押しすると **ピン留め** や **ゴミ箱へ移動**
- 本文に `#tag` と書くだけでタグが自動で認識されます

このあとの 3 つのスターターノートでは Markdown、タグ整理、データが端末に残る仕組みを紹介します。どれも自由に編集・削除できます。 #start #ガイド

# Markdown できれいに書く

Markdown は平文として読みやすさを保ちながら、構造とスタイルを表現できます。Markleaf は入力中にシンタックスをハイライトし、**プレビュー** ではクリーンな表示にレンダリングします。

## ツールバー早見表

- **H** は行頭を `#`、`##`、`###`、なし の順に切り替えます
- 箇条書き / 番号付き / チェックリストのボタンは行頭プレフィックスを切り替えます
- 太字、斜体、取り消し線、インラインコードは選択範囲を囲みます
- 引用・コードブロック・区切り線はブロック要素を挿入します
- リンクは `[ラベル](URL)` テンプレートを挿入します

## スマート Enter

リスト / チェックリスト / 引用行の末尾で Enter を押すと、次の行に同じプレフィックスが自動で付きます。番号付きリストは番号が増えます。空のプレフィックス行で Enter を押すとリストを終了します。

## よく使う構文

- **太字** と _斜体_
- ~~取り消し線~~
- `インラインコード`
- [ ] 未完了タスク
- [x] 完了タスク
- > 短い引用

```kotlin
fun hello() = "Markleaf"
```

# タグで整理する

Markleaf はフォルダではなくタグを中心に整理されています。1 つのノートに好きなだけタグを付けられます。

## #タグを本文中に書く

本文のどこにでも #プロジェクト、#会議、#読書 のように書くと、**タグ** 画面に表示されます。タグをタップするとそのタグでノートを絞り込めます。

## ピン留めとグループ

ピン留めしたノートは **ピン留め** セクションとして一覧の上部に表示されます。それ以外は更新日順に **今日**、**昨日**、**過去 7 日間**、**それ以前** にグループ化されます。

ノートを長押しでピン留め、ピン留め済みノートを再度長押しで解除。 #整理

# データはこの端末に残ります

Markleaf は INTERNET 権限を宣言していません。アカウントもアナリティクスも広告もサーバーもありません。ノートはあなたが他の場所に移そうと決めるまで、ローカルの Room データベースに残ります。

## ノートを持ち出す

- システム共有シートから単一ノートを Markdown として共有
- 全ノートを指定フォルダに `.md` ファイルとしてエクスポート
- ゴミ箱内のノートは完全削除前なら復元できます

ゴミ箱は誤削除に対する取り消しボタンです。ゴミ箱に移動したノートは **ゴミ箱** 画面から復元できます。 #バックアップ #プライバシー
