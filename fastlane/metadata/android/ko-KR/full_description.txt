Markleaf는 Android용 로컬 우선(local-first) Markdown 메모 앱입니다.

표준 Markdown으로 빠르게 쓰고, 본문 안의 태그로 정리하고, 로컬에서 즉시 검색하세요. 노트는 기기 내부 Room 데이터베이스에 저장되며 Markleaf는 INTERNET 권한을 선언하지 않습니다.

작성과 미리보기:

* 실시간 Markdown 미리보기와 라이브 syntax 컬러링
* GFM 표, 체크박스, 인용문, 콜아웃(> [!NOTE] …)
* 10개 언어 코드 블록 syntax highlighting
* 각주 ref ↔ def 점프, 위키링크와 백링크
* 선택 영역이나 단어를 굵게/기울임/취소선/코드로 감싸는 스마트 포맷팅
* 포커스 모드, 단어·읽기 시간 통계, 노트 안에서 찾기·바꾸기

정리와 탐색:

* 본문에 #태그만 쓰면 자동 인덱싱 (폴더 불필요)
* 빠른 이동(Quick Switcher)과 SQLite FTS 전문 검색
* 고정, 보관, 휴지통, 복원 흐름

동기화와 가져오기 (No-Cloud):

* 사용자가 선택한 SAF 폴더로 각 노트를 .md 파일로 미러링
* 외부 .md / .txt 파일을 열기·공유로 가져오기
* 단일 노트 및 전체 노트 Markdown 내보내기, 시스템 공유

디자인과 접근성:

* 홈 화면 위젯, 생체 인증 잠금, 스크린샷 차단 옵션
* 라이트 / 다크 / Material You, 태블릿 2-pane 레이아웃
* 6개 언어 UI (한국어, 영어, 스페인어, 일본어, 프랑스어, 독일어)

개인정보와 배포 원칙:

* 계정 없음, Markleaf 서버 없음
* 분석, 광고, 추적, Firebase, 폐쇄형 크래시 리포팅 SDK 없음
* INTERNET 권한 없음, Android 자동 백업 제외
* 데이터는 내보내기, 공유, 외부 링크 열기, 사용자가 선택한 SAF 폴더 같은 명시적 OS 경로를 통해서만 기기 밖으로 이동합니다
