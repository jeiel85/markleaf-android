실제 글쓰기 흐름

도구는 조용히 물러나고,
글은 계속 이어집니다.

열기, 쓰기, 정리, 찾기, 내보내기까지 한 기기 안에서 자연스럽게 이어집니다.

01 · 쓰기

문법은 살아나고, 도구는 필요할 때만 나타납니다.

Markdown 원문은 그대로 유지하면서 헤딩과 강조가 편집 중에도 읽기 좋게 표현됩니다. 작은 Aa 버튼과 선택 문맥 액션, 줄 시작의 / 명령으로 화면을 어지럽히지 않고 서식을 넣습니다.

  • Live Markdown과 CommonMark/GFM 미리보기
  • 서식 툴바, 직접 만드는 스니펫 버튼, 키보드 단축키
  • 표·콜아웃·위키링크까지 빠른 삽입

02 · 정리하고 찾기

폴더를 고민하기 전에 태그하고, 연결하고, 검색합니다.

본문의 #태그가 바로 분류가 되고, SQLite FTS 검색과 Quick Switcher가 많은 노트 속에서도 다음 생각으로 빠르게 이동시킵니다.

  • 중첩 태그와 태그별 노트 탐색
  • 위키링크와 백링크
  • 여러 노트를 한 번에 골라 고정·아카이브·휴지통으로

03 · 소유하고 옮기기

앱 밖에서도 읽히는 파일로 남깁니다.

전체 노트를 표준 Markdown으로 내보내거나, 사용자가 고른 SAF 폴더에 미러링할 수 있습니다. PDF 공유가 필요할 때도 원본 .md는 그대로 남습니다.

  • 단일·전체 Markdown 내보내기
  • 사용자 선택 폴더 미러
  • 이미지까지 담는 PDF 내보내기와 Android 공유 시트

04 · 쓰던 폴더 그대로

이미 쓰고 있는 Markdown 폴더를 그대로 가리키세요.

Markleaf에는 자체 볼트 형식이 없습니다. Obsidian이나 Logseq, 텍스트 에디터가 만들어 둔 파일을 그대로 노트로 받아들이고, 그 파일이 지니고 있던 프론트매터는 손대지 않고 돌려줍니다.

  • 기존 .md 파일을 복제하지 않고 그대로 인수
  • 다른 도구가 쓴 프론트매터 키는 왕복해도 보존
  • 폴더 한 겹만 — Markleaf는 폴더 대신 태그로 정리
실제 볼트에 연결하기 전에 알아둘 것

그 밖에도

작은 기능들을
매주 하나씩 더해 왔습니다.

상당수가 Issues나 Discussions에 올라온 요청에서 시작했습니다. 새 버전은 거의 매주 나옵니다.

  • 홈 화면 위젯

    최근 노트 목록이나 노트 하나를 고른 색으로 두고, 배경화면이 원하는 만큼 비치게 할 수 있습니다.

  • 오늘의 노트

    새 노트 바로가기가 날짜를 제목으로 한 그날의 노트를 열어, 바로 한 줄을 이어 쓸 수 있습니다.

  • 잠긴 노트

    일부 노트는 암호 뒤에 두고, 앱 전체를 잠그고, 스크린샷과 최근 앱 화면에서 노트를 가릴 수 있습니다.

  • 태블릿과 폴더블

    태그 레일·노트 목록·편집기를 나란히 두고, 화면을 돌려도 열린 노트가 그대로 남습니다.

  • 나만의 모양

    Markleaf 그린 또는 Material You, 다크 모드, 줄 간격, 직접 고른 .ttf·.otf 글꼴.

  • 이미지

    대체 텍스트와 함께 이미지를 첨부합니다. 앱 저장소 안에 머물고 PDF에도 함께 들어갑니다.

  • 어떤 Markdown 파일이든 읽기

    .md나 .txt 파일을 열면 렌더링된 상태로 읽습니다. 저장해야만 노트에 들어옵니다.

  • 너그러운 휴지통

    휴지통으로 옮긴 직후 실행 취소하거나 나중에 복원하고, 정한 기간이 지나면 저절로 비우게 할 수 있습니다.

Privacy by architecture

보내지 않는 것이
가장 분명한 보호입니다.

F-Droid·Google Play 빌드는 인터넷 권한을 아예 선언하지 않습니다. 노트, 태그, 첨부, 설정은 사용자가 직접 이동을 선택하기 전까지 앱 전용 저장소에 머물며, 어느 빌드에서도 전송되지 않습니다.

F-Droid / Google Play: android.permission.INTERNET = false

예외는 하나뿐입니다. GitHub Releases의 -sideload APK는 업데이트를 확인할 수 있지만, 사용자가 켜야만 동작하고 그때도 노트 데이터는 보내지 않습니다.
