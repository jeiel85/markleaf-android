真实的写作流程

工具退到后面，
文字持续流动。

打开、书写、整理、查找、导出 — 全部在一台设备上自然衔接。

01 · 书写

语法活了起来，工具只在需要时出现。

Markdown 原文保持不变，标题和强调在编辑过程中依然清晰易读。一个小小的 Aa 按钮、随选区出现的操作，以及行首的 / 命令，让你在不弄乱屏幕的前提下添加格式。

  • 实时 Markdown 与 CommonMark/GFM 预览
  • 格式工具栏、自定义片段按钮和键盘快捷键
  • 表格、提示块与 Wiki 链接的快速插入

02 · 整理与查找

在纠结文件夹之前，先打标签、建链接、做搜索。

正文里的 #标签 就是你的分类方式，SQLite FTS 搜索与快速切换让你在大量笔记之间也能迅速跳到下一个想法。

  • 嵌套标签与按标签浏览笔记
  • Wiki 链接与反向链接
  • 一次选中多条笔记，置顶、归档或移入回收站

03 · 拥有与迁移

留下离开应用也能读的文件。

把所有笔记导出为标准 Markdown，或镜像到你自己选择的 SAF 文件夹。即使需要分享 PDF，原始的 .md 也原样保留。

  • 单篇与全部笔记的 Markdown 导出
  • 镜像到你选择的文件夹
  • 带图片的 PDF 导出，以及 Android 分享面板

04 · 沿用你自己的文件夹

直接指向你已经在用的 Markdown 文件夹。

Markleaf 没有自己的知识库格式。Obsidian、Logseq 或文本编辑器已经写好的文件会被直接当作笔记接管，而它们自带的 frontmatter 会原封不动地写回去。

  • 接管现有的 .md 文件，而不是复制一份
  • 其他工具写入的 frontmatter 字段往返后依然保留
  • 只读取一层文件夹，不递归子目录 — Markleaf 用标签来整理
指向真实知识库之前需要知道的事

还有这些

小功能，
每周添一点。

其中很多来自 Issues 或 Discussions 里的请求。几乎每周都会发布新版本。

  • 主屏幕小部件

    最近的笔记列表或单条笔记，用你选的颜色，还能按喜好透出壁纸。

  • 今日笔记

    让新建笔记的快捷方式打开当天的笔记：以日期为标题，随时再添一行。

  • 锁定的笔记

    把部分笔记放在密码之后，锁定整个应用，并让笔记不出现在截图和最近任务中。

  • 平板和折叠屏

    标签栏、笔记列表和编辑器并排显示，旋转屏幕时打开的笔记保持不变。

  • 你的外观

    Markleaf 绿或 Material You、深色模式、行距，以及你自己的 .ttf / .otf 字体。

  • 图片

    附加带替代文字的图片。图片保存在应用内部，也会一起导出到 PDF。

  • 阅读任意 Markdown 文件

    打开 .md 或 .txt 文件即可渲染阅读，只有保存后才会加入你的笔记。

  • 宽容的回收站

    移入回收站后可立即撤销，之后也能恢复，或让回收站在你设定的期限后自动清空。

Privacy by architecture

什么都不发送，
就是最清晰的保护。

F-Droid 与 Google Play 版本完全不声明联网权限。笔记、标签、附件与设置都留在应用私有存储中，直到你自己决定把它们移出去 — 任何版本都不会发送它们。

F-Droid / Google Play: android.permission.INTERNET = false

唯一的例外：GitHub Releases 上的 -sideload APK 可以检查更新，但只有在你开启后才会运行，而且同样不会发送任何笔记数据。
