# Markleaf에 오신 것을 환영합니다

Markleaf는 Android용 로컬 우선 Markdown 노트 앱입니다. 빠르게 열리고, 조용히 쓸 수 있고, 본문은 항상 plain Markdown으로 보관됩니다.

## 먼저 해볼 것

- 우측 하단 **+** 를 눌러 새 노트 만들기
- 툴바로 제목·목록·굵게·코드·인용 같은 서식 적용하기
- 상단의 **미리보기** 를 눌러 렌더링된 모습 확인하기
- 노트를 **길게 눌러** 상단 고정하거나 휴지통으로 보내기
- 본문 안에 `#태그` 를 입력하면 자동으로 태그가 인식됩니다

뒤이은 세 개의 노트가 Markdown 사용법, 태그 정리, 그리고 데이터가 어떻게 기기에 머무는지를 다룹니다. 어느 것이든 자유롭게 수정하거나 삭제해도 됩니다. #시작 #가이드

# Markdown으로 예쁘게 쓰기

Markdown은 글을 plain text로 두면서도 구조와 강조를 함께 표현할 수 있는 방식입니다. Markleaf는 입력하는 동안 문법을 실시간으로 하이라이팅하고, **미리보기** 모드에서 깔끔하게 렌더링해 보여줍니다.

## 툴바 한눈에 보기

- **H** 버튼은 줄을 `#`, `##`, `###`, 평문으로 순환시킵니다
- 글머리 기호 / 번호 / 체크박스 버튼은 줄 앞 prefix를 토글합니다
- 굵게, 기울임, 취소선, 인라인 코드는 선택 영역을 감쌉니다
- 인용, 코드 블록, 구분선은 블록 요소를 삽입합니다
- 링크 버튼은 `[라벨](대상)` 템플릿을 넣어줍니다

## 스마트 Enter

목록·체크리스트·인용 줄 끝에서 Enter를 누르면 다음 줄에 같은 prefix가 자동으로 들어갑니다. 번호 매기기는 자동 증가하며, prefix만 있고 비어 있는 줄에서 Enter를 누르면 목록이 종료됩니다.

## 자주 쓰는 문법

- **굵게**, _기울임_
- ~~취소선~~
- `인라인 코드`
- [ ] 할 일
- [x] 완료한 일
- > 짧은 인용

```kotlin
fun hello() = "Markleaf"
```

# 태그로 정리하기

Markleaf는 폴더보다 태그 중심입니다. 한 노트에 원하는 만큼 태그를 붙일 수 있습니다.

## 본문에 #태그 쓰기

본문 어디든 #프로젝트, #회의, #독서처럼 태그를 적으면 **태그** 화면에 모입니다. 태그를 누르면 그 태그가 달린 노트만 필터링됩니다.

## 고정과 그룹

상단 고정한 노트는 **고정됨** 섹션에 모이고, 나머지는 시점별로 **오늘**, **어제**, **지난 7일**, **이전** 으로 자동 그룹화됩니다.

노트를 길게 눌러 상단 고정하거나, 이미 고정된 노트를 다시 길게 눌러 고정 해제할 수 있습니다. #정리

# 데이터는 이 기기에만 머뭅니다

Markleaf는 INTERNET 권한을 선언하지 않습니다. 계정, 분석, 광고, 서버 연동도 없습니다. 노트는 사용자가 직접 어디론가 보내기 전까지 로컬 Room 데이터베이스 안에만 존재합니다.

## 노트를 기기 밖으로

- 공유 시트로 단일 노트를 Markdown으로 공유할 수 있습니다
- 전체 노트를 사용자가 선택한 폴더에 `.md` 파일로 내보낼 수 있습니다
- 휴지통으로 보낸 노트는 영구 삭제 전에 복원할 수 있습니다

휴지통은 실수에 대한 안전망입니다 — 휴지통으로 보낸 노트는 **휴지통** 화면에서 다시 복원할 수 있습니다. #백업 #프라이버시
