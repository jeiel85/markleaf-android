# Markleaf에 오신 것을 환영합니다

Markleaf는 Android용 조용한 로컬 우선 Markdown 노트북입니다. 빠르게 열리고, 글쓰기를 방해하지 않으며, 내 글을 내가 소유한 plain text로 남깁니다.

## 아주 짧은 둘러보기

- **아름다운 Markdown 캔버스**에서 글쓰기 표면을 확인해보세요.
- **매일 쓰는 글쓰기 루틴**은 일기처럼 쓰는 예시입니다.
- **프로젝트 브리프**는 작업, 링크, 구조를 함께 담는 예시입니다.
- 앱 밖의 파일이 필요하면 **로컬 폴더 미러**를 열어보세요.

> [!TIP]
> 이 노트들은 모두 일반 노트입니다. 편집하거나, 내보내거나, 휴지통으로 보내거나, 더 이상 필요 없으면 삭제해도 됩니다.

# 아름다운 Markdown 캔버스

![Markleaf 샘플 캔버스](attachments/starter-note-2/markleaf-sample-cover.png)

Markdown은 편집 중에도 읽기 쉬운 텍스트이고, **미리보기**에서는 차분하고 정돈된 문서가 됩니다.

## 이 노트가 보여주는 것

- **굵게**, _기울임_, ~~취소선~~, `인라인 코드`
- 제목, 목록, 체크리스트, 인용문, 구분선, 코드 블록, 표, 콜아웃, 각주, 링크, 이미지
- 입력하는 동안 바로 보이는 라이브 문법 스타일

> [!NOTE]
> 상단 바에서 편집과 미리보기를 오가보세요. 노트는 여전히 Markdown 텍스트입니다.

| 요소 | 쓰임 |
| --- | --- |
| `#tag` | 정리 |
| `[[프로젝트 브리프]]` | 로컬 노트 링크 |
| `![](...)` | 이미지 첨부 |

```kotlin
fun markleaf() = "local-first markdown"
```

작은 각주는 본문 흐름을 끊지 않고 세부 정보를 곁에 둡니다.[^1]

[^1]: 각주, 콜아웃, 표, 코드 블록은 모두 기기 안에서 렌더링됩니다.

# 로컬 폴더 미러

Markleaf에는 자체 클라우드가 필요 없습니다. 사용자가 폴더를 하나 고르면, Android나 사용자가 선택한 동기화 도구가 그 폴더를 다룹니다.

## 일어나는 일

- Markleaf는 각 노트를 Markdown 파일로 씁니다.
- frontmatter의 `markleaf_id`가 안정적인 연결을 유지합니다.
- 첨부파일은 미러된 노트 곁에 함께 보관됩니다.
- 앱은 여전히 INTERNET 권한을 선언하지 않습니다.

## 왜 중요한가요?

내 노트는 다른 Markdown 도구에서도 읽을 수 있고, 동기화 방식은 사용자가 고를 수 있습니다.
