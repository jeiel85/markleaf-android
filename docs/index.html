Current App

글쓰기 흐름을 방해하지 않는 Markdown 작업대

Live Markdown

헤딩, 굵게, 취소선, 인라인 코드가 편집 중에도 즉시 살아납니다. v2.16.2의 스마트 토글은 선택 영역과 커서 주변 단어를 자연스럽게 감쌉니다.

정리와 탐색

본문 안의 `#태그`, SQLite FTS 검색, Quick Switcher, 위키링크와 백링크로 로컬 노트를 빠르게 찾습니다.

Markdown 호환성

GFM 표, 체크박스, 콜아웃, 각주, YAML frontmatter, 코드 블록 하이라이팅, PDF와 `.md` 내보내기를 지원합니다.

Android다운 마감

Material 3, 다크 모드, 태블릿 2-pane, 홈 화면 위젯, 생체 인증 잠금, 스크린샷 보호 옵션을 갖췄습니다.

Privacy Model

서버 없이, 계정 없이, 네트워크 권한 없이

Markleaf 자체는 `android.permission.INTERNET`을 선언하지 않습니다. 노트, 태그, 첨부, 설정은 기기 안에 머물고, 사용자가 직접 export/share 하거나 SAF 폴더를 선택할 때만 OS 경로를 통해 이동합니다.

폴더 미러는 Drive, Dropbox, Syncthing, OneDrive 같은 외부 동기화 앱이 선택한 폴더를 처리하도록 맡기는 방식입니다. Markleaf 서버와 백엔드는 없습니다.
