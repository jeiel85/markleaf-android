Politique de confidentialité de Markleaf

Dernière mise à jour : 26 mai 2026 · S'applique à Markleaf Android v2.x

Principe fondamental

Markleaf est une application de notes Markdown local-first. Markleaf lui-même n'a pas la permission android.permission.INTERNET, n'exploite aucun serveur propre, et ne télécharge jamais automatiquement de notes, étiquettes, pièces jointes ou métadonnées vers un serveur externe.

Informations que Markleaf ne collecte pas

  • Nom, e-mail, contacts, localisation
  • Informations de compte ou de connexion
  • Corps de la note, titre, étiquettes, images jointes, noms de fichiers, métadonnées
  • Statistiques d'utilisation, télémétrie, événements d'analyse, identifiants publicitaires
  • Rapports de plantage ou identifiants d'appareil

Elle ne contient pas non plus d'analyse, de publicité, de suivi, de configuration à distance, de Firebase, ni de SDK de rapport de plantage à code source fermé.

Réseau

Markleaf ne déclare aucune permission internet.

android.permission.INTERNET   aucune

Où sont stockées les données

  • Le contenu des notes, les titres et l'index des étiquettes sont stockés dans la base de données Room interne de l'application.
  • Les paramètres utilisateur sont stockés dans DataStore.
  • Les images jointes sont copiées dans le stockage interne de l'application, les métadonnées EXIF sensibles étant supprimées lors de l'enregistrement.

Politique de sauvegarde du système Android

Markleaf définit android:allowBackup="false" pour exclure les données de l'application de la sauvegarde automatique Android et du transfert d'appareil à appareil. Si vous devez passer à un nouvel appareil ou utiliser plusieurs appareils, c'est vous qui choisissez l'export Markdown, le partage, ou un miroir de dossier SAF.

Mouvement de données initié par l'utilisateur

Les actions suivantes ne se produisent que lorsque vous les effectuez vous-même, via la boîte de dialogue de permission explicite d'Android ou un choix que vous faites dans l'interface.

  • Exporter une note ou toutes les notes au format Markdown (.md)
  • Partager le texte d'une note ou des fichiers via la feuille de partage du système Android
  • Appuyer sur un lien externe dans le corps du texte pour le déléguer au système / au navigateur par défaut
  • Copier dans le presse-papiers
  • Refléter les fichiers Markdown dans un dossier SAF de votre choix

La synchronisation d'un dossier SAF par un client de synchronisation externe comme Drive, Dropbox, OneDrive, Syncthing ou un montage NAS relève de la responsabilité de cette application externe. Markleaf n'effectue pas cette synchronisation lui-même.

Autorisations

La seule permission de type runtime que déclare Markleaf est android.permission.VIBRATE pour le retour haptique. Elle ne déclare aucune permission de localisation, microphone, appareil photo, contacts, notifications, lecture du stockage externe, lecture des médias ou réseau.

Contact

Pour toute question ou signalement de sécurité/confidentialité, contactez-nous via GitHub Issues.
