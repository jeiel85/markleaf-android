Markleaf Privacy Policy

Last updated: May 26, 2026 · Applies to Markleaf Android v2.x

핵심 원칙

Markleaf는 로컬 우선 Markdown 노트 앱입니다. Markleaf 자체에는 android.permission.INTERNET 권한이 없고, 자체 서버를 운영하지 않으며, 노트/태그/첨부/메타데이터를 자동으로 외부 서버에 업로드하지 않습니다.

Markleaf가 수집하지 않는 정보

  • 이름, 이메일, 연락처, 위치
  • 계정 또는 로그인 정보
  • 노트 본문, 제목, 태그, 첨부 이미지, 파일명, 메타데이터
  • 사용 통계, 텔레메트리, 분석 이벤트, 광고 식별자
  • 크래시 리포트 또는 기기 식별자

분석, 광고, 추적, 원격 설정, Firebase, 폐쇄형 크래시 리포팅 SDK도 포함하지 않습니다.

네트워크

Markleaf는 인터넷 권한을 선언하지 않습니다.

android.permission.INTERNET   없음

데이터 저장 위치

  • 노트 본문, 제목, 태그 인덱스는 앱 내부 Room 데이터베이스에 저장됩니다.
  • 사용자 설정은 DataStore에 저장됩니다.
  • 첨부 이미지는 앱 내부 저장소에 복사되어 보관되며, 저장 시 민감한 EXIF 메타데이터를 제거합니다.

Android 시스템 백업 정책

Markleaf는 android:allowBackup="false"를 설정해 Android Auto Backup 및 기기 간 전송에서 앱 데이터를 제외합니다. 기기 이전 또는 다중 기기 사용이 필요하다면 사용자가 직접 Markdown 내보내기, 공유, 또는 SAF 폴더 미러를 선택해야 합니다.

사용자 주도 데이터 이동

다음 동작은 사용자가 직접 실행한 경우에만 일어나며, Android의 명시적 권한 다이얼로그 또는 사용자 UI 선택을 거칩니다.

  • 단일 노트 또는 전체 노트를 Markdown(.md)으로 내보내기
  • Android 시스템 공유 시트로 노트 텍스트 또는 파일 공유
  • 본문 안의 외부 링크를 탭해 OS/기본 브라우저에 위임
  • 클립보드로 복사
  • 사용자가 선택한 SAF 폴더로 Markdown 파일 미러링

SAF 폴더가 Drive, Dropbox, OneDrive, Syncthing, NAS 마운트 같은 외부 동기화 클라이언트에 의해 동기화될지는 해당 외부 앱의 책임입니다. Markleaf는 그 동기화 자체를 수행하지 않습니다.

권한 목록

Markleaf가 선언하는 런타임 성격의 권한은 햅틱 피드백을 위한 android.permission.VIBRATE뿐입니다. 위치, 마이크, 카메라, 연락처, 알림, 외부 저장소 읽기, 미디어 읽기, 네트워크 관련 권한은 선언하지 않습니다.
