01 · 쓰기

문법은 살아나고, 도구는 필요할 때만 나타납니다.

Markdown 원문은 그대로 유지하면서 헤딩과 강조가 편집 중에도 읽기 좋게 표현됩니다. 작은 Aa 버튼과 선택 문맥 액션, 줄 시작의 / 명령으로 화면을 어지럽히지 않고 서식을 넣습니다.

  • Live Markdown과 CommonMark/GFM 미리보기
  • 13개 포맷팅 액션과 외장 키보드 단축키
  • 표·콜아웃·위키링크까지 빠른 삽입

02 · 정리하고 찾기

폴더를 고민하기 전에 태그하고, 연결하고, 검색합니다.

본문의 #태그가 바로 분류가 되고, SQLite FTS 검색과 Quick Switcher가 많은 노트 속에서도 다음 생각으로 빠르게 이동시킵니다.

  • 중첩 태그와 태그별 노트 탐색
  • 위키링크와 백링크
  • 고정·아카이브·휴지통 복구

03 · 소유하고 옮기기

앱 밖에서도 읽히는 파일로 남깁니다.

전체 노트를 표준 Markdown으로 내보내거나, 사용자가 고른 SAF 폴더에 미러링할 수 있습니다. PDF 공유가 필요할 때도 원본 .md는 그대로 남습니다.

  • 단일·전체 Markdown 내보내기
  • 사용자 선택 폴더 미러
  • PDF와 Android 공유 시트

04 · 쓰던 폴더 그대로

이미 쓰고 있는 Markdown 폴더를 그대로 가리키세요.

Markleaf에는 자체 볼트 형식이 없습니다. Obsidian이나 Logseq, 텍스트 에디터가 만들어 둔 파일을 그대로 노트로 받아들이고, 그 파일이 지니고 있던 프론트매터는 손대지 않고 돌려줍니다.

  • 기존 .md 파일을 복제하지 않고 그대로 인수
  • 다른 도구가 쓴 프론트매터 키는 왕복해도 보존
  • 폴더 한 겹만 — Markleaf는 폴더 대신 태그로 정리
실제 볼트에 연결하기 전에 알아둘 것

Privacy by architecture

보내지 않는 것이
가장 분명한 보호입니다.

Markleaf 자체는 인터넷 권한을 선언하지 않습니다. 노트, 태그, 첨부, 설정은 사용자가 직접 이동을 선택하기 전까지 앱 전용 저장소에 머뭅니다.

android.permission.INTERNET = false 개인정보 보호 정책 자세히 보기
  1. 1 기기 안에 저장

    Room DB와 앱 전용 첨부 저장소

  2. 2 사용자가 직접 선택

    Export · Share · SAF 폴더

  3. 3 선택한 경로로 이동

    Markleaf 서버나 백엔드 없음
